# NORTHHELD

Мультиплеер для The Long Dark: 2–4 игрока в одном мире через Steam.

Скачать: **[последний выпуск](https://github.com/chistowhite/northheld-releases/releases/latest)** → файл `NORTHHELD.exe`.

## Как установить

**Что нужно**

- Windows 10 или 11, 64-бит.
- The Long Dark **из Steam**, версия 2.55. Версии из Epic Games Store и Game Pass не подходят.
- Хотя бы один раз запустить игру через Steam до установки мода.
- Быть в друзьях Steam с тем, кто создаёт комнату: комнаты видны только друзьям.

**Шаги**

1. Откройте [последний выпуск](https://github.com/chistowhite/northheld-releases/releases/latest) и в разделе **Assets** скачайте
   **`NORTHHELD.exe`**. Не zip-архив и не «Source code».
2. Положите `NORTHHELD.exe` в любую папку (например, на рабочий стол) и запустите.
3. Если Windows пишет **«Система Windows защитила ваш компьютер»**, нажмите **«Подробнее» → «Выполнить в любом случае»**.
   Лаунчер не подписан платным сертификатом, поэтому Windows его не узнаёт.
4. Лаунчер сам найдёт игру в Steam. Если не нашёл, нажмите **«Выбрать папку игры…»** и укажите папку, где лежит `tld.exe`
   (обычно `C:\Program Files (x86)\Steam\steamapps\common\TheLongDark`).
5. Нажмите **«Установить»**. Лаунчер один раз скачает мод и нужные компоненты с их официальных страниц: MelonLoader (GitHub),
   .NET 6 (Microsoft) и модель игрока SkyCoop (GitHub) — всего около 100 МБ.
6. Нажмите **«Играть»**. В главном меню игры появится меню NORTHHELD (**F8** — показать или скрыть).

## Как играть вместе

- **Хост:** «Создать игру» → настройки → «Создать комнату» → «Пригласить друга».
- **Друг:** «Присоединиться» → комната хоста в списке.
- В игре: **F6** — общее сохранение (у хоста), **F9** — отчёт о проблеме (у друга — «Передать хосту»), **F3** — сведения для разработки.

## Обновления

Лаунчер сам проверяет обновления при запуске — кнопка **«Обновить до …»**. Вместе можно играть только на одной версии,
обновляйтесь оба.

## Если не запускается

- **При запуске `NORTHHELD.exe` ничего не происходит.** Откройте «Безопасность Windows» → «Защита от вирусов и угроз» →
  «Журнал защиты». Если там есть `NORTHHELD.exe`, нажмите «Разрешить». Браузер мог предупредить «файл может быть опасен» —
  выберите «Сохранить» и скачайте заново.
- **«NORTHHELD уже запущен».** Окно уже открыто — найдите его на панели задач.
- **Игра без меню NORTHHELD.** Запускайте игру кнопкой **«Играть»** в лаунчере: запуск из Steam открывает обычную игру без мода.
- **Не видно комнату друга.** Вы должны быть друзьями в Steam и на одной версии NORTHHELD.
- Если ничего не помогло, пришлите тому, кто вас пригласил, файл `%LOCALAPPDATA%\NORTHHELD\logs\launcher.log`
  (вставьте путь в адресную строку проводника) и снимок экрана.

## Как удалить

В лаунчере **«Удалить мод»** — игра снова станет обычной. **«Играть без мода»** запускает обычную игру через Steam.
